# Context Index

All agents read this file first. It maps every context file and what it contains.

## Framework files (always present)

| File | Purpose |
|------|---------|
| [project-overview.md](project-overview.md) | App description, users, environments, automation repo path |
| [roles.md](roles.md) | User roles, permissions, modules, env variable names for credentials |
| [test-standards.md](test-standards.md) | Priority scale, naming rules, scope, out-of-scope areas |
| [automation-guide.md](automation-guide.md) | Generated by framework-analyzer: framework, structure, patterns |

## Module files (added by the user, one per feature)

Module files live in `context/modules/`. Each file covers one feature area of your application.

**You create these.** See `context/modules/README.md` for the template and instructions.

Agents discover module files dynamically using `context/modules/*.md` — no registration needed.
